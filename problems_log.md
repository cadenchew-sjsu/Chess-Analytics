## Nov 15: GitHub Desktop showed no changes
- **What happened:** No files were synced up to the Github desktop
- **Error or symptom:** "No local changes" 
- **Cause:** My new cloned files from Github weren't in the VS Code and I hadn't  saved yet. this caused Github desktop to not detect any changes I was making on VS Code.
- **Fix:** Saved files in VS Code, checked that both apps pointed at the same folder instead of having 2 folders with the same title or purpose.
- **What I learned:** All programs should correspond with the same folder, Git ignores empty folders and anything in .gitignore.
